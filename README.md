# StoryBoardStudio

> 
> 基于 Gradio 的影视分镜表可视化编辑与资产预览工具，Excel 驱动，支持图片 / 音频 / 视频多媒资产联动预览。

## ✨ 核心特性

- 📊 **Excel 原生驱动**：直接读取 `.xlsx` 分镜表，支持多 Sheet 切换，修改后一键回写保存
- 🖼️ **图片资产预览**：按编码自动匹配图片，支持缩略网格与灯箱放大查看
- 🔊 **音频资产预览**：多轨音频编码匹配，内置播放器与进度条
- 🎬 **视频资产预览**：按镜头号自动匹配视频，小窗悬停控制、灯箱放大、播放进度同步
- 🎛️ **精细视图控制**：列宽 / 行高缩放、单列显示隐藏、一键适配宽度、布局记忆
- 📝 **提示词大字区**：选中行自动展开完整提示词，支持换行与空行
- 🌙 **深色沉浸主题**：暗色界面，聚焦分镜内容

## 🚀 快速开始

### 环境要求

- Python 3.10+
- macOS（启动脚本为 Mac 定制）

### 启动方式

1. 双击运行 `launch_SBS_mac.command`
2. 脚本会自动创建虚拟环境、安装依赖、启动服务并打开浏览器
3. 默认访问地址：`http://localhost:7861`

### 手动启动

```
# 激活虚拟环境
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动服务
python app.py
```

## 📖 功能说明

### 表格列定义

表格

| 列 | 说明 |
| --- | --- |
| A. 镜头号 | 镜头唯一编号，用于视频自动匹配 |
| B. 小标题 | 镜头简短描述 |
| C. 时长 | 镜头时长（秒 / 帧均可） |
| D. 图片资产 | 参考图编码，竖线分隔多图 |
| E. 声音资产 | 音频编码，支持多轨叠加 |
| F. 生视频提示词 | 完整画面描述，支持多行 |
| G. 视频结果 | 按镜头号自动匹配对应视频 |

### 视图操作

- **栏宽收窄 / 拉宽**：整体缩放所有列宽度
- **行高收紧 / 拉开**：整体缩放所有行高度
- **适配宽度**：一键缩放至刚好适配当前窗口
- **记住排版**：保存当前视图比例到本地
- **恢复默认**：重置为初始视图比例
- **隐藏 / 显示列**：自定义显示需要的列

### Excel 同步

- 点击「💾 同步并保存到 Excel」即可将网页修改写回原文件
- 保存前自动备份原文件到 `_backups` 目录
- 保存时请关闭正在打开的 Excel 文件，避免占用冲突

## 📁 项目结构

```
StoryBoardStudio/
├── app.py                  # 主程序
├── requirements.txt         # Python 依赖
├── launch_SBS_mac.command  # Mac 一键启动脚本
├── push_sbs.command        # GitHub 自动推送脚本
├── update_sbs.txt          # GitHub 自动更新脚本
├── gradio_temp/            # 本地配置缓存
└── _backups/               # Excel 自动备份目录
```

## ⚠️ 注意事项

- 首次运行会自动创建 Python 虚拟环境 `venv`
- 资产文件需放置在配置的「资产目录」下
- 视频文件按镜头号命名即可自动匹配，支持 `mp4 / mov / webm / mkv`
- 建议使用 Chrome / Safari 最新版浏览器访问
